WinHash · tối đa 3 tài khoản chạy song song
⚠️ Đây là trang chạy hoàn toàn trên trình duyệt của bạn (không có server trung gian) — mỗi tài khoản gọi thẳng API bằng chính mạng/IP của máy đang mở trang. Muốn 3 tài khoản chạy ở 3 IP khác nhau thật sự, hãy mở file này trên 3 máy/trình duyệt (hoặc 3 profile có proxy riêng) khác nhau — bản thân trang này không tự đổi IP giúp bạn. Nếu API báo lỗi mạng/CORS, có thể trình duyệt đang chặn request cross-origin tới api.winhash.net.
